# Assignment #1 - HTML & CSS Basics
This project was created for Assignment #1 in Web Programming.

## Project Description
The project demonstrates the basic use of HTML and CSS. It includes several webpages with different layouts, styles, content, tables, and forms.

### Task 1 - Personal Webpage
A personal webpage introducing the author. It contains information about me, my skills and hobbies, as well as links and an image. CSS is used to style the page, including colors, fonts, spacing, borders, and layout.

### Task 2 - Simple Webpage Layout
A simple website layout created using `<div>` elements and CSS positioning. The page contains a header, navigation bar, left sidebar, main content area, and footer. The navigation bar connects the different tasks of the assignment.

### Task 3 - Tribute Page
A tribute page dedicated to Fyodor Mikhailovich Dostoevsky. It includes a short biography, important events from his life, key contributions, an image, and useful links. Different CSS properties are used to create the page design.

### Task 4 - Table and Feedback Form
A student grades table styled with CSS, including borders, alternating row colors, a highlighted row, and merged cells. The page also contains a feedback form with text and email fields, a role selection, radio buttons, comments, and a submit button.

## How to Use
1. Open the project repository.
2. Open `tasktwo2/twoo.html` in a web browser.
3. Use the navigation bar to move between Tasks 1, 2, 3, and 4.
4. Each task can also be opened directly from its corresponding folder.
